## IMPLEMENTATION NOTES FOR BUILD TEAM

**Scroll architecture:** Seven sections, single-column, generous vertical padding between movements. The environmental layers (GSAP parallax, neural scaffolding, grain) continue functioning as built — the content rides on top of what's already working.

**What gets removed:** The B-A-S-E letter constellation, the bilateral shift grid, the three method cards (BASE/SPACE/WAVES), and the current CTA section. The scroll counter can remain as ambient interface.

**What gets preserved:** Nav bar, environmental layer stack, GSAP scroll controller, footer structure. The scroll-reveal observer pattern (`.reveal` → `.visible`) applies to every content element as currently implemented on Origin.

**Typography mapping:** Headlines in Cinzel. Body copy in IBM Plex Mono. Signal lines and accent lines per the existing color system — primary (#E8E3FF), turquoise (#58FCC8), secondary (#9994B8), dim (#5A5672). The content document marks which register each element uses.

**Content column:** Max-width 900px, centered, with 40px horizontal padding — matching Origin's `.content-column` class.

**Density:** The homepage is the most compressed page on the site. Vertical whitespace between sections should be generous (16vh–30vh padding), but the text within each section is tight. No decorative elements between sections. The architecture creates pace through breathing room, not ornament.

**No bilateral grid.** The entire page is single-column narrative. The shift from left/right contrast to single-column is the design matching the content: the homepage is not a comparison. It is a progression. Each section earns the next.

**Filter lines (Section 7):** These are stacked short declarations, same treatment as Origin's Movement 6 `.filter-line` class.

**Jargon boundary:** Framework terminology ("signal literacy," "competent material," "metabolic forcing" as named concepts, BASEWAVES as methodology name) does not appear until Section 5. Sections 1–4 use the concepts without naming them. The visitor encounters the felt experience first, the name second. This is structural, not stylistic.
